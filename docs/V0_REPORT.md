# 受约束 GEMM V0 工程报告

2026-11-22，Asia/Shanghai。**报告与证据复算已完成，P1-05 最终计时未验收，尚未生产发布。** 当前仅支持可信 CUDA 模板的参数提案、正确性、计时、NCU 反馈、外置裁决和离线回放。

初始、当前与 best 都是同一 4-warps CUDA 实现，identity `f329ade329014e517bf5e3b3a5828f7bc1b1c86102ffc310a6519110e85426a6`；本轮复用 binary SHA256 `93fb2f4344521b7e9b246b54d1c30d4b1a8facf731e6385e18f6119e9c49c72c`。名义 agent 收益 1.0、胜／平／负 0/8/0，来自实现身份相同，不来自对噪声数据的胜负分类。

## 独立最终复测

8 个开发 workload × 重复输入／16 输入轮转 × 3 独立进程；4 个封存独立验收 workload 未执行。GPU 空闲窗口串行运行，普通 CUDA Graph Event，关闭 profiler。沿用 KernelBench 接入、冻结合同、CPU FP64 参考、原检查与 Graph 顺序。

首批 1,728 个主复测段的 A/A 最坏偏离 3.042%，超过原单对 2% 界限。根据该批段长预先冻结一次约 250ms 长段计划，再运行三进程共 864 段；100ms 草案未执行并保留。唯一计时函数逻辑改动是将写死的 replay=12 参数化，CPU 审计核对其余函数体相同。原搜索协议／门槛未改。

追加长段仍有两组 dev-03（M=1,N=4096,K=512）越界：session 0 重复输入最坏偏离 3.216%，session 2 轮转输入 3.324%。因此 `summary.status=TIMING_NOT_ACCEPTED`，不删异常段、不再追加挑选通过批次，不出具稳定最终性能结论。段长约 254–270ms，已有证据不足以把原因归为单一 host、驱动或时钟问题。

| 缓存策略 | 8 项初始／best 几何均值（描述性） | 探索性 session 区间 |
|---|---:|---|
| 重复输入 | 0.999840 | [0.999203, 1.000478] |
| 16 输入轮转 | 0.999824 | [0.998229, 1.001421] |

这些区间基于 3 session 的 mean log ratio 和 t(2)=4.303，仅供描述；A/A 未通过时不能用聚合接近 1.0 掩盖单对失败。

另开三进程，同一 binary 中的 `gemm_cublas` 对冻结 4-warps，864 个原始段单列。比值定义为 **cuBLAS_latency / 模板_latency**，不是 agent 主收益。

| 1024,1024,1024 | 77.224 | 214.109 | 0.3600 |
| 1,4096,512 | 12.093 | 12.080 | 1.0012 |
| 8,1024,1024 | 11.061 | 11.059 | 1.0000 |
| 32,512,2048 | 9.312 | 17.779 | 0.5236 |

| 1024,256,768 | 17.171 | 42.627 | 0.4027 |
| 127,1009,513 | 12.765 | 12.781 | 0.9996 |

全 8 项等权几何均值：重复输入 0.5825、轮转输入 0.5581，即当前模板整体延迟约为 cuBLAS 的 1.7–1.8 倍。M=1/8 及非整齐项走同一 cuBLAS 回退，接近 1.0；Tensor Core 模板覆盖项明显落后。**生产默认实现应优先选 cuBLAS，4-warps 只保留作搜索参照**；发布策略与自动运行时分派仍待实现和验收。Event 覆盖 GPU 流窗口，不能直接视为 eager 部署端到端延迟。

## 证据、复现与限制

- 本轮共 3,456 个原始 Event 段、672 组测前／后正确性检查，9 个 GPU worker 正常退出；worker 墙钟合计约 522.3 秒。这不是全部 GPU 忙碌时间或两次模型调用总成本。
- CPU 审计 `PASS` 只说明源绑定、原始数据复算、历史裁决回放与记账一致；同一文件明确 `final_timing_accepted=false`、`PENDING_TIMING_STABILITY`。
- 完整隔离、全新安装、模型生成源码、连续多轮服务、独立验收与发布回滚尚未整体验收。未读取封存清单内容或将其传给候选／模型。
- 学习复盘、Softmax／Attention／MLA 和跨 GPU 仍在后续计划。
